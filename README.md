# UEFormat

A Plugin that can imports exported ueanim's and uemodel's from FModel or from UModel 

This Plugin was orginally based on a Blender Plugin but TBC created a UPlugin out of it for 4.23, shout out to her.
Anyways then Kiro forked the UPlugin and made a compatible 4.26 version out of it, it somehow doesnt work anymore so yeah
and i started doing a version for 4.25
